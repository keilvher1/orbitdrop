Privacy statement

Last updated: 12 November 2026

  • OrbitDrop processes your files on your own computer. It never uploads them.
  • There is no account, and no usage statistics or crash reports are sent.
  • The only network use is an optional update check.
  • This website uses no cookies and no analytics.

This statement explains what the OrbitDrop desktop app (macOS, Windows) and this website keep, and where. OrbitDrop is open source under the MIT licence; its source code is public on GitHub.

The app

Your files

Every conversion and edit happens on your computer. File contents and file names are never sent anywhere. Results are saved next to the original (or in a folder you choose); the original is never moved, overwritten or deleted.

What is stored on your computer

OrbitDrop keeps the following on your computer only, and never sends it anywhere:

  • Settings (settings.json) — your choices, such as the language, the shortcuts and the save location
  • Job history (history.json) — names, sizes, states and output paths of the last 100 jobs. Never file contents.
  • Logs (logs/main.log) — for troubleshooting. They contain no document contents and no full paths.
  • Caches — temporary data the app creates while it works
  • Crash dumps — may be written if the app crashes; they stay on your computer and are never sent.
Data locations by operating system
SystemLocation
macOS~/Library/Application Support/OrbitDrop

This data stays when you remove the app. You can delete it at any time; the FAQ explains how.

Network

The only time OrbitDrop uses the internet is the optional update check. When it checks for updates, OrbitDrop asks GitHub for the latest version. With that request GitHub receives the app version and normal HTTP metadata (your IP address, the time of the request and so on). No files, file names, settings or job history are sent. GitHub handles this information under the GitHub General Privacy Statement.

If you do not use the update check, OrbitDrop does not connect to the internet. Links inside the app (for example to GitHub) open in your default web browser.

Permissions

OrbitDrop does not use accounts, the camera, the microphone, location or contacts. On macOS the global drag needs no permission, and OrbitDrop never records keystrokes, pointer positions or window information. See the FAQ for details.

This website

  • This site is hosted on GitHub Pages. GitHub logs visitors’ IP addresses for security purposes (GitHub Pages documentation). See the GitHub General Privacy Statement.
  • It uses no cookies, no analytics, no ads, and no external fonts or scripts.
  • To show the latest version, the download section of the home page asks the GitHub API (api.github.com) directly from your browser. GitHub receives normal HTTP metadata such as your IP address with that request too. With JavaScript turned off, the request is not made.
  • Download links fetch the files from GitHub.

Questions and changes

Questions or requests are welcome in GitHub issues. If this statement changes, this page and its date are updated; earlier versions are in the change history on GitHub.
