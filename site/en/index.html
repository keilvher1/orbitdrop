Free, open-source desktop app · macOS · Windows (beta)

Drag a file, press Shift, drop it on a format.

OrbitDrop opens a radial wheel next to the pointer when you press Shift while dragging a file in Finder or File Explorer. Drop the file on a format or a tool and the result appears next to the original, which stays untouched.

How it works

Three steps

No window to open first. Drag a file as usual and press one more key.

  1. 1

    Drag a file

    Drag a PDF or an image in Finder or File Explorer as you normally would. Several files at once work too (some tools take one file at a time).

  2. 2

    Press Shift

    The convert wheel appears next to the pointer. On macOS, Option+Shift opens the tools wheel instead. You can change the tools menu shortcut in Settings. The wheel stays until you drop or cancel, even after you let go of the key.

  3. 3

    Drop it on a sector

    The result is saved in the same folder as the original. The original is never moved, overwritten or deleted. Dropping on the centre of the wheel does nothing.

Prefer not to drag?

Choose Open File… from the OrbitDrop icon in the menu bar (the notification area on Windows), or drop files on the small Drop Zone window. You get the same wheel, and you can also pick with the arrow keys and Enter.

Formats

What it converts

The wheel only offers formats that really work for the file you are dragging. There is no fake conversion that just renames the extension.

The Windows version uses the same conversion engines but has not been checked on a real PC yet (beta). HEIC is not supported on Windows. Sectors the bundled engines cannot handle are disabled on the wheel, with the reason. There is no OCR, video or audio conversion, AI or cloud feature.

Tools

The image tools wheel

On macOS, press Option+Shift while dragging an image to open the tools wheel. You can change the tools menu shortcut in Settings. Picking a tool opens a small editor window.

  • Crop

    Free, 1:1, 16:9, 9:16, 4:3 or 3:4, or an exact size in pixels.

  • Add Background

    Preset, solid or image backgrounds with padding, rounded corners and a shadow. The preview is the result.

  • Compress

    Pick a format and the longest side, and see the expected size before you save.

  • Metadata

    Shows camera details and location (GPS), and saves a copy without the metadata.

  • Edit

    Rotate, flip, and adjust brightness, contrast and saturation.

  • Annotate

    Text (including Korean), arrows and rectangles, with undo and redo.

  • Redact

    Solid boxes or mosaic. The result keeps no thumbnail of the original and no metadata.

Privacy

Your files are processed on your computer

OrbitDrop does every conversion and edit on your own computer. The only feature that sends a file anywhere is the optional Claude analysis, which you turn on yourself.

  • Offline conversions and edits

    Converting and editing never sends file contents or names anywhere. Every conversion and edit works without an internet connection.

  • No account

    Nothing to sign up for, nothing to sign in to.

  • No telemetry

    No usage statistics, no crash reports. Settings, job history and logs stay on your computer.

  • Online in two places only

    For the optional update check, GitHub receives the app version and normal connection data such as your IP address. Claude analysis, off until you turn it on, sends only the files you drop on “ANALYZE” to Anthropic with your own API key.

System requirements

Where it runs

macOS

  • macOS 14 Sonoma or later
  • Separate installers for Apple silicon (arm64) and Intel (x64).
  • Checked from drag to result in the real Finder on macOS 14 and macOS 26 virtual machines (Apple silicon). No one has checked it on a physical Mac yet.
  • The Intel build has only been checked under Rosetta 2 on Apple silicon, not yet on an Intel Mac.

Windows

Beta
  • Windows 11 x64
  • The installer is built to install for the current user, without administrator rights.
  • Not yet run on a real Windows PC: neither the installer nor the global drag has been checked. Why beta?
  • Windows on ARM and Linux are not supported.

Check the download (SHA-256)

If the release includes SHA256SUMS.txt, you can make sure the file was not changed on the way: compare the output of the command below with the line for the same file name in that file. The two values must match.

macOS — Terminal

shasum -a 256 ~/Downloads/OrbitDrop-*-mac-*.dmg

Windows — PowerShell

Get-FileHash "$env:USERPROFILE\Downloads\OrbitDrop-*-setup.exe" -Algorithm SHA256

When a release includes SHA256SUMS.txt, a link to it appears here. You can also find it on GitHub Releases.

FAQ

Frequently asked questions

Which permissions does OrbitDrop need on macOS?

None that you have to grant. The global drag is built to work without Accessibility or Input Monitoring permission, and OrbitDrop shows no permission prompt when it starts. It does not ask for Full Disk Access either.

  • Notifications — the first time a job started from a drag finishes, macOS asks whether OrbitDrop may show notifications. Conversions work either way.
  • Input Monitoring — only if you have already granted it can Esc close the wheel while the pointer is outside it. Without it, Esc works while the pointer is over the wheel, and outside the wheel it closes when you finish the drag as usual. OrbitDrop never requests this permission.
  • Protected locations — in places macOS protects, such as iCloud Drive or external and network volumes, macOS may ask for access. If you decline, only jobs in that location fail, and you can choose another place to save.

Windows has no such permission prompts. If only one of OrbitDrop and File Explorer runs as administrator, drags between them are blocked, so run both normally.

What happens on first launch?

On macOS, open the DMG, drag OrbitDrop to the Applications folder and launch it. On Windows, the installer is built to install for the current user (by default in %LOCALAPPDATA%\Programs\OrbitDrop) without asking for administrator rights. The Windows version is a beta (see “Why is the Windows version a beta?”).

On first launch a small welcome window explains how to use it once: your current shortcuts, where the icon lives and an “Open OrbitDrop at login” switch (off at first). After that OrbitDrop runs without a window, as an icon in the menu bar (the notification area of the taskbar on Windows — Windows 11 may hide new icons under ^): drag a file and press Shift. Settings are under Settings… in the icon’s menu, and Help › How to Use opens the welcome window again.

On first launch the interface follows your system language (Korean, otherwise English). You can change it in Settings… › General › Language.

Running the Intel build on an Apple silicon Mac makes the first launch slow while Rosetta 2 translates it (about 1 minute 40 seconds in a virtual machine), and OrbitDrop then suggests installing the Apple silicon build.

Where is the icon?

macOS — on the right side of the menu bar at the top of the screen. It does not appear in the Dock. If a crowded menu bar hides it, open OrbitDrop again from the Applications folder: the running OrbitDrop shows its Drop Zone window.

Windows — in the notification area at the right end of the taskbar. If you cannot see it, click the up arrow (show hidden icons). Starting OrbitDrop again also opens the Drop Zone window.

How do I uninstall it, and where does its data live?

macOS

  1. Choose Quit from the menu-bar icon.
  2. Move OrbitDrop from the Applications folder to the Trash.
  3. If you turned on “Open OrbitDrop at login”, also remove it in System Settings › General › Login Items. If you added OrbitDrop to Accessibility or Input Monitoring yourself, remove it in System Settings › Privacy & Security.

Settings (settings.json), job history (history.json), logs (logs/main.log) and caches stay after the app is removed. Delete them yourself if you like: ~/Library/Application Support/OrbitDrop and ~/Library/Preferences/io.github.keilvher1.orbitdrop.plist.

Windows

Settings › Apps › Installed apps › OrbitDrop › Uninstall (or Uninstall OrbitDrop.exe in the install folder). The uninstaller removes the install folder, the shortcuts, the uninstall entry and the start-at-login entry.

Your data in %APPDATA%\OrbitDrop (settings, job history, logs, caches) is kept. To remove it as well, delete that folder or uninstall with this command (default install location):

"%LOCALAPPDATA%\Programs\OrbitDrop\Uninstall OrbitDrop.exe" --delete-app-data

Converted and edited files are saved next to the originals, so they stay when you remove the app.

Why is the Windows version a beta?

Because no person has checked it on a real Windows 11 PC yet. The installer is built on GitHub’s Windows Server 2025 runners (virtual machines), where it passes install, uninstall and launch tests and an automated test that drags real files in a real File Explorer window, presses Shift to open the wheel and drops on a format (nine cases, including cancelling, dropping outside the ring and dragging text). That input is synthesized, only 100 % scaling with one monitor was covered, and the tools menu and editors have not been checked on Windows yet. The installer is not code-signed yet, so Windows may show a warning (the Code signing policy describes the signing plan). The macOS version was checked from drag to result in the real Finder on macOS 14 and macOS 26 virtual machines.

  • If only one of OrbitDrop and File Explorer runs as administrator, drags between them are blocked.
  • HEIC conversion is not supported on Windows.
  • You can change the tools menu shortcut in Settings.
  • If dragging does not work, Open File… and the Drop Zone in the icon’s menu do the same job.

Found a problem? Please report it in GitHub issues.

Where are results saved, and under which names?

In the same folder as the original. Page 001.pdf becomes Page 001.jpg; a PDF with several pages becomes report-p001.jpg, report-p002.jpg and so on. Tool results get the tool in the name: photo Cropped.jpg, photo Cropped With Background.png.

If a file with that name already exists, OrbitDrop never overwrites it and uses a new name such as photo (2).jpg. If the original folder is not writable, it asks where to save. You can also set the save location to “Ask every time” in Settings.

The wheel does not appear.
  • Check the global drag status in the menu of the menu-bar (notification-area) icon. If it is off, turn on Enable Global Drag.
  • Folders, text snippets and cloud files that are not downloaded yet cannot be processed; the reason appears under the wheel.
  • The key combinations for both wheels can be checked and changed in Settings.
  • Meanwhile, Open File… and Open Drop Zone in the icon’s menu give you the same wheel.
