개인정보 처리방침

최종 수정일: 2026년 11월 12일

  • OrbitDrop은 변환과 편집을 모두 내 컴퓨터에서 처리합니다. 파일을 업로드하지 않습니다.
  • 예외는 직접 켜는 Claude 분석 하나입니다. 휠의 ‘Claude 분석’에 놓은 파일만 내 API 키로 Anthropic에 보내 분석합니다. 처음에는 꺼져 있습니다.
  • 계정이 없고, 사용 통계나 충돌 보고서를 보내지 않습니다.
  • 인터넷을 쓰는 곳은 선택 사항인 업데이트 확인과, 직접 켠 Claude 분석 두 가지뿐입니다.
  • 이 웹사이트는 쿠키와 분석 도구를 쓰지 않습니다.

이 문서는 OrbitDrop 데스크톱 앱(macOS, Windows)과 이 웹사이트가 어떤 정보를 어디에 두는지 설명합니다. OrbitDrop은 MIT 라이선스의 오픈 소스이며, 소스 코드는 GitHub에 공개되어 있습니다.

앱

파일

변환과 편집은 모두 내 컴퓨터에서 처리합니다. 파일의 내용과 이름은 어디로도 보내지 않습니다. 직접 켠 Claude 분석에 놓은 파일만 예외입니다. 결과 파일은 원본 옆(또는 직접 고른 폴더)에 저장되며, 원본은 옮기거나 덮어쓰거나 지우지 않습니다.

내 컴퓨터에 저장되는 정보

OrbitDrop은 다음 정보를 내 컴퓨터에만 저장하고, 외부로 보내지 않습니다.

  • 설정(settings.json) — 언어, 단축키, 저장 위치 같은 선택 사항
  • 작업 기록(history.json) — 최근 작업 100개의 파일 이름, 크기, 상태, 결과 파일 경로. 파일 내용은 저장하지 않습니다.
  • 로그(logs/main.log) — 문제를 찾기 위한 기록. 문서 내용과 전체 경로는 남기지 않습니다.
  • 캐시 — 앱이 동작하면서 만드는 임시 데이터
  • 충돌 덤프 — 앱이 비정상 종료될 때 만들어질 수 있으며, 내 컴퓨터에만 남고 전송되지 않습니다.

앱을 지워도 이 데이터는 남습니다. 언제든 직접 지울 수 있으며, 방법은 자주 묻는 질문에 있습니다.

네트워크

OrbitDrop이 인터넷을 쓰는 곳은 두 가지입니다. 하나는 선택 사항인 업데이트 확인이고, 다른 하나는 직접 켜야 동작하는 Claude 분석입니다. 업데이트를 확인할 때 OrbitDrop은 GitHub에 최신 버전을 묻습니다. 이 요청으로 GitHub은 앱 버전과 일반적인 HTTP 메타데이터(IP 주소, 요청 시각 등)를 받습니다. 파일, 파일 이름, 설정, 작업 기록은 보내지 않습니다. GitHub이 이 정보를 다루는 방식은 GitHub 개인정보 처리방침을 따릅니다.

업데이트 자동 확인은 처음에 켜져 있습니다(실행 1분 뒤, 그 뒤 6시간마다). 끄는 방법은 세 가지입니다: Windows 설치 프로그램의 ‘개인정보와 업데이트’ 단계에서 ‘업데이트 자동 확인’을 해제(1.0.1부터, 무인 설치는 /NOUPDATECHECK), 처음 실행할 때 열리는 환영 창의 같은 스위치, 또는 설정 › 일반 › ‘업데이트 자동 확인’. 꺼 두어도 정보 창의 ‘지금 확인’으로 직접 확인할 수 있습니다.

업데이트 확인을 끄고 Claude 분석을 켜지 않으면 OrbitDrop은 인터넷에 연결하지 않습니다. 앱 안의 링크(예: GitHub 페이지)를 누르면 기본 웹 브라우저가 그 페이지를 엽니다.

Claude 분석 (선택 기능)

Claude 분석은 처음에 꺼져 있습니다. 설정 › Claude 분석에서 직접 켜고 본인의 Anthropic API 키를 넣어야 동작합니다. 켜 두어도 파일을 휠의 ‘Claude 분석’에 놓기 전에는 아무것도 보내지 않습니다.

파일을 ‘Claude 분석’에 놓으면 OrbitDrop은 그 파일을 내 컴퓨터에서 Anthropic API(api.anthropic.com)로 바로 보내 분석을 요청하고, 받은 보고서를 원본 옆에 Markdown 파일(… Analysis.md)로 저장합니다. 요청은 OrbitDrop 개발자의 서버를 거치지 않으며, 개발자는 그 내용을 볼 수 없습니다. 이때 보내는 정보는 다음과 같습니다.

  • 파일 내용 — 이미지는 긴 변을 1568픽셀 이하로 줄인 사본(JPEG 또는 PNG), PDF는 파일 그대로(100쪽·20MB 이하)
  • 파일 이름과 보고서 언어
  • 설정에 적어 둔 추가 요청(적었을 때만)
  • 인증에 쓰는 API 키

Anthropic은 이 요청을 Anthropic의 API 이용 약관과 개인정보 처리방침에 따라 처리합니다. 사용 요금은 그 API 키의 계정에 청구됩니다. 민감한 파일은 이 기능에 놓지 마세요.

API 키는 운영체제의 보안 저장소(macOS 키체인, Windows 데이터 보호 API)로 암호화해 이 컴퓨터에만 저장합니다. 설정 파일, 로그, 작업 기록에는 남기지 않으며, 설정 › Claude 분석에서 언제든 지울 수 있습니다. 분석 보고서와 작업 기록은 다른 결과 파일과 똑같이 내 컴퓨터에만 남습니다.

권한

OrbitDrop은 계정, 카메라, 마이크, 위치, 연락처를 쓰지 않습니다. macOS에서 전역 드래그에 필요한 권한은 없으며, 키 입력, 마우스 위치, 창 정보를 기록하지 않습니다. 자세한 내용은 자주 묻는 질문에 있습니다.

이 웹사이트

  • 이 사이트는 GitHub Pages에서 제공됩니다. GitHub은 보안을 위해 방문자의 IP 주소를 기록합니다(GitHub Pages 문서). 자세한 내용은 GitHub 개인정보 처리방침을 보세요.
  • 쿠키, 분석 도구, 광고, 외부 글꼴이나 외부 스크립트를 쓰지 않습니다.
  • 첫 페이지의 다운로드 영역은 최신 버전을 보여 주려고 브라우저에서 GitHub API(api.github.com)에 직접 요청합니다. 이 요청에서도 GitHub은 IP 주소 같은 일반적인 HTTP 메타데이터를 받습니다. 자바스크립트를 끄면 이 요청은 일어나지 않습니다.
  • 다운로드 링크를 누르면 GitHub에서 파일을 받습니다.

문의와 변경

질문이나 요청은 GitHub 이슈로 남겨 주세요. 이 방침이 바뀌면 이 페이지와 최종 수정일을 고치며, 바뀐 내용은 GitHub의 변경 기록에서 볼 수 있습니다.
