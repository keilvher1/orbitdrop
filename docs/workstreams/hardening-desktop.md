## Contract changes (packages/contracts/src/ipc.ts, additive only)

- `IPC_CHANNELS.windowCloseGuard` (`orbit:window:close-guard`, renderer → main, send) with `WindowCloseGuardRequestSchema` `{ guard: boolean }` (strict).
- `IPC_CHANNELS.windowCloseRequested` (`orbit:window:close-requested`, main → one renderer).
- `OrbitApi.setCloseGuard?(guard)` and `OrbitApi.onCloseRequested?(listener)` — optional, so other implementations keep compiling.
- `AppInfo.notices?: readonly StartupNotice[]` and `StartupNotice { code: 'settingsReset' | 'historyReset'; backup: string | null }`.

Nothing else: #31 (smoke `window`) is main-only, #32 uses the field the lead committed in `helper-protocol.ts`.

## `ORBITDROP_SMOKE` line (#31)

New field `window`, part of `ok` and of the exit code. From this dev Mac
(`ORBITDROP_DISABLE_HELPER=1 electron apps/desktop --smoke-test --smoke-optional-helper`, built tree):

```json
"window": { "ok": true, "view": "about", "ms": 295, "loaded": true, "preload": true, "rendered": true, "shown": false, "error": null, "consoleErrors": [] }
```

A window that cannot load its page reports e.g. `"ok": false, "loaded": false, "error": "did-fail-load ERR_CONNECTION_REFUSED (-102)"`
(a blank packaged window would show `ERR_FILE_NOT_FOUND (-6)`); one that loads
but never renders reports `"error": "not rendered within 15 s (loaded true, preload …, view …, version …, stylesheets n/m)"`.
`consoleErrors` (first 5, e.g. CSP violations) are diagnostics only.

## Not fixed / open

- Quitting with an editor that has unsaved work does not ask: the task requires that quitting always works, and the before-quit handler never waits for a renderer.
- Not GUI-verified (no synthesized OS input on this Mac): a real ⌘W key press (the menu item exists in the running app; the close path is exercised through `BrowserWindow.close()`, which is what `performClose:` triggers), Alt+F4 and log-off on Windows, re-opening the app from Finder (`activate`), `open-file` from Finder, real sleep / screen lock (the powerMonitor events are emitted in the E2E run), the login-item adoption (packaged builds only), the smoke `window` check inside a real package (the lead re-packages).
- Windows: after a log-off that another app cancels, close guards stay off until OrbitDrop restarts (there is no "session end cancelled" event). The "Animation effects" setting can be up to 30 s stale (#18; no change event exists).
- Editors are a fixed 520 px panel: in a window narrower than that (small or zoomed displays, which main never produces on a normal display) they scroll sideways, and Add Background asks for 675 px on 600–690 px work areas (`RESERVED_HEIGHT`). Needs a fluid editor width with the preview sized from the measured width.
- `—` is used as an empty value / estimate (Compress, Metadata, Settings); screen readers say "em dash" or skip it. `HelperStatus.reason` comes from the helpers in English (noted before).
- Forced colours: Redact's selected area keeps its accent border instead of Highlight (visible). Batch Compress could only be checked in unit tests (the harness opens no multi-file Compress).
- Crop shows real validation errors in a `role="alert"` that mounts and unmounts; a persistent polite error container would be gentler.
- The PDF-order editor's renderer asks for each thumbnail once per open editor window: a file replaced while that window is open keeps its first thumbnail there (main's and the worker's caches now render it again whenever it is asked for); the output always reads the file at commit time.
- From the lead (#31): serve the UI from a custom `app://` protocol so the `GrantFileProtocolExtraPrivileges` fuse can go back off (needs the scheme registered as privileged before `ready`, `isTrustedUrl` / navigation guards / CSP moved to that origin, and the dev-server path kept); take the AppUserModelID from a single source (`index.ts` hard-codes `app.orbitdrop.desktop`, which must equal `appId` in `electron-builder.yml` — e.g. a check in `scripts/package.mjs`, or reading it from the packaged `package.json`).
